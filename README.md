# 燕云浮层提醒器

Windows 桌面浮层，识别失魂与笛子图标，提供倒计时、声音提醒和全局暂停快捷键。包含可选的截图 / 录屏捕获开关。

## Windows 启动提醒器

1. 安装 [Python 3.12（64 位）](https://www.python.org/downloads/windows/)，保留 Python Launcher 与 Tcl/Tk 安装选项。
2. 克隆本仓库，或点击 **Code → Download ZIP** 并解压。
3. 双击 `start-windows.bat`。首次运行会创建 `.venv` 并联网安装依赖，随后打开提醒器。
4. 在「常用设置 → 浮层位置 / 音效设置」点击「预览并拖动」，拖动后点击「保存并关闭」。可切换文字 / 图标模式，分别勾选失魂和笛子的声音，选择电子音、百度语音或自定义 WAV。笛子图标只显示使用后的技能冷却倒数；完整冷却默认 24 秒，尚未使用时不会起算。

也可以在 PowerShell 手动启动：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe buff_reminder_v2_dizi_hotkey.py
```

两个选区、笛子校准、浮层文字与图标设置保存在 `%APPDATA%\尘Buff提醒器_追踪明度版\config.json`，选一次后重启直接使用。自定义音频保存在同目录的 `audio` 子目录。后续更新代码不会清空个人设置。

### 游戏监测设置

现在直接使用 `yysls_export` 中的失魂、Debuff 框和笛子原图，**不需要另找三个旧版模板文件**。请下载完整仓库，不要只复制主 Python 文件；运行时还会使用同目录的 `reminder_*.py`、图标和音效文件。

1. 保持「模板与遮罩」中的三项为空，即使用原图模式。如果以前填过旧模板路径，清空三项并保存。
2. 点击「框选敌方 Buff 栏」，框住要检测的整行，四周保留约 12 像素余量。默认旗框宽度约 48 像素；UI 缩放不同可在「高级参数 → 频率 / 原图匹配 → 原图模式旗框宽度」调整，搜索会覆盖该宽度附近的多个尺寸。
3. 让笛子处于可用、亮起状态，点击「设置笛子图标」。5 秒后冻结截图，紧贴笛子图案框选并按 Enter；程序用原图对齐，再保存屏幕位置和亮度检测区域。分辨率或 UI 布局变化后重新设置。
4. 开始监测，确认状态显示「原图定位 / 原图追踪」及身份分数。原图模式通过相对近期亮度的跃升或倒计时扇区回跳确认刷新，每次刷新重新起轴，不再要求先暗到旧版低阈值。首次挂上仍需连续高亮确认。

识别不到目标时立即隐藏对应浮层图标。奇术栏消失不会启动笛子 24 秒冷却，重新出现时已变暗也不推测使用时间。检测频率、原图匹配分数与刷新参数可在「高级参数 → 频率 / 原图匹配」调整，笛子参数在「笛子检测」调整。

详见 [浮层与音效说明](docs/reminder-controls.md)。声音和全局快捷键使用 Windows 接口；macOS 不适合作为完整功能测试环境。


## 录制浮层

在「常用设置 → 浮层位置 / 音效设置」勾选「允许截图/录屏捕获浮层」，然后保存或预览。默认关闭。录屏软件请选择显示器 / 桌面捕获，并将浮层移出 Buff 栏及笛子检测区域；遮挡检测区时程序会跳过该帧识别。

## 隐私

截图识别在本机进行，提醒器运行时不上传画面，也不调用在线语音服务。首次安装依赖需要联网。

个人配置、自定义声音、校准和手动导出的调试画面保存在本机用户目录，不属于本仓库。反馈问题前请检查截图中的角色名、聊天、账号及本机路径。

## 开发与测试

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p "test_*.py" -v
```

测试涵盖录屏开关及遮挡保护、拖动、配置保存、声音、识别与计时。测试图仅包含裁剪后的单个技能图标；完整游戏截图和私人样本集不随仓库发布。因此这里的测试不代表完整实战识别率。Windows 多屏、录屏软件和游戏实际显示效果仍需实机验证。
