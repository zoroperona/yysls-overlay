# 燕云浮层提醒器

《燕云十六声》Windows 桌面辅助工具。识别屏幕上的 Buff 和奇术图标，在独立浮层显示倒计时并播放提醒音。支持同时勾选多个项目，各自保存检测区域、独立计时；支持选择是否让截图 / 录屏捕获浮层。

## 已支持的流派与技能

这里的“支持”指下表中的图标监控，不代表完整流派循环或自动操作。流派称呼按提供的信息记录，不推断未确认的归属。

| 流派 / 分类 | 监控项 | 类型 | 配置时长 | 提醒方式 |
| --- | --- | --- | --- | --- |
| 威威 | 威威易伤 | Buff | 16 秒 | 效果临近结束提醒 |
| 无名 | 真气失衡 | Buff | 15 秒 | 效果临近结束提醒 |
| 尘尘 | 失魂落魄 | Buff | 21 秒 | 原有失魂识别、刷新与临近结束提醒 |
| 通用奇术 | 骑龙回马 | 奇术 | 12 秒 | 确认可用时提醒；确认使用后显示冷却 |
| 通用奇术 | 千灯一月 | 奇术 | 40 秒 | 确认可用时提醒；确认使用后显示冷却 |
| 通用奇术 | 笛子（沿用原界面称呼） | 奇术 | 24 秒 | 原有笛子校准、可用及重复提醒 |

名称、时长和图标路径定义在仓库根目录的 [skills.json](skills.json)。程序启动时读取；修改后重启软件。`cd` 对 Buff 表示**持续时间**，对奇术表示**使用后的冷却时间**，单位均为秒。配置表中的默认时长在启动 / 开始监测时生效。

## Windows 安装与运行

1. 安装 [Python 3.12（64 位）](https://www.python.org/downloads/windows/)，保留 Python Launcher、pip 与 Tcl/Tk 选项。
2. 下载完整仓库（Code → Download ZIP），或者下载 Release 的 `yysls-overlay.zip`，解压到普通文件夹。不要只复制主 Python 文件。
3. 双击 `start-windows.bat`。首次运行创建 `.venv` 并联网安装依赖，以后直接启动。
4. 打开主界面的「监控列表」，勾选需要的项目。默认保留原有失魂和笛子，新项目需自行勾选。
5. 点击每项的「设置检测区域」，完成设置后回到主界面点击「开始监测」。

也可在 PowerShell 手动运行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe buff_reminder_v2_dizi_hotkey.py
```

## 多项监控与校准

- **新增 Buff / 奇术**：让目标图标亮起；点击该项「设置检测区域」，确定后 5 秒冻结截图，紧贴完整图案框选并按 Enter，Esc 取消。避免包含倒计时数字、边框、邻近图标；校准时会验证原图匹配，空白区域无法通过。
- **每项单独选区**：威威易伤、真气失衡、骑龙回马和千灯一月互不共用校准数据。选择多个项目后同时运行。在「监控列表」可查看各项状态。
- **失魂落魄**：继续使用原来的「框选敌方 Buff 栏」，在整个选区内搜索和追踪目标；「模板与遮罩」三项留空即可使用随包原图。
- **笛子**：继续使用原来的「设置笛子图标」，在可用亮起状态校准。原有独立声音与重复提醒设置保留。
- 修改勾选或校准会停止监测，设置完成后重新开始。NumLock 默认全局暂停 / 继续，可在主界面更改。

新增项目使用**固定检测区域内的原图匹配和相对亮度**，支持局部尺寸偏差，不会在整屏自动寻找图标。Buff 栏图标换槽、移动，或游戏分辨率、UI 缩放、技能栏位置变化后，应重新框选。图标消失时隐藏对应浮层；奇术栏消失不会被判定为释放技能。

Buff 连续确认亮起后建立时间轴，相对亮度连续跃升后确认刷新；不是直接读取游戏倒计时数字。如果启动时 Buff 已经生效一段时间，首次推算可能偏晚，应等待下一次施加 / 刷新。奇术必须先确认亮起，再连续确认变暗，才开始冷却；启动时已经在冷却不会猜测剩余秒数。到零只表示推算到期，实际重新可用仍以图标变亮确认。

## 浮层、声音与录屏

「常用设置 → 浮层位置 / 音效设置」可切换文字 / 图标模式。图标模式按勾选顺序展示多个槽位，分别绘制倒计时；未确认起始时刻显示 `?`。点击「预览并拖动」调整位置。

新增项目使用通用电子提示音，文字提醒包含技能名，避免误播“笛子好了”等其他技能语音。同一检测轮内的多个文字提醒合并显示。主界面「声音提醒」「画面提醒」总开关对所有项目生效。

默认不允许截图或录屏捕获浮层。需要录制时勾选「允许截图/录屏捕获浮层」，保存或预览后生效。录屏软件请选择显示器 / 桌面捕获，将浮层移出检测区域；遮挡时该项跳过识别，其他未遮挡项目继续监测。

原有失魂、笛子的详细设置见 [浮层与音效说明](docs/reminder-controls.md)。

## 自己添加技能、Buff 或奇术

无需改 Python 代码，通用识别适用于**透明背景、白色图案**的图标。彩色照片、无透明通道或复杂动态图标不属于当前通用检测器的支持范围。

1. 准备目标的透明背景 RGBA PNG，只把需要的一张图放入 `assets/icons/`，例如 `assets/icons/my_qishu.png`。不要复制整个素材库，也不要用带角色名、聊天或账号信息的截图。
2. 编辑根目录 `skills.json`，在 `skills` 数组中追加项目。保持合法 JSON，项目之间加逗号，最后一项后不要加逗号。示例中的 `my_qishu.png` 需由你自己提供：

```json
{
  "id": "my_qishu",
  "name": "我的奇术",
  "school": "通用奇术",
  "kind": "qishu",
  "cd": 30,
  "icon": "assets/icons/my_qishu.png"
}
```

添加 Buff 时使用 `"kind": "buff"`，`cd` 填效果持续时间；添加奇术或同类亮暗冷却技能时使用 `"kind": "qishu"`，`cd` 填使用后的完整冷却时间。

| 字段 | 规则 |
| --- | --- |
| `id` | 稳定且唯一的小写英文标识，可含数字、下划线，以字母开头；不要复用其他项目的 ID |
| `name` | 软件中展示和提醒使用的技能名 |
| `school` | 流派 / 分类说明；可省略，默认“自定义” |
| `kind` | `buff` 或 `qishu`，决定计时语义 |
| `cd` | 大于 0、不超过 3600 的秒数，支持小数 |
| `icon` | 仓库内 PNG 的相对路径，使用 `/`；不允许绝对路径或 `..` |

3. 保存后重启软件，打开「监控列表」，新项目自动出现。
4. 在亮起状态设置它的检测区域，勾选后开始监测。更新 PNG、游戏布局或缩放后重新校准。

新增项目**不要填写 `engine`**，默认走通用检测器。原有 `loss` / `dizi` 的 `engine` 用于兼容专用失魂追踪、笛子校准；请保留它们的 ID、类型、引擎和原图路径。通用项目可增删；改 ID 会视为新项目，需要重新勾选和校准。

## 配置保存与隐私

个人选区、校准亮度、勾选状态和浮层设置保存在 `%APPDATA%\尘Buff提醒器_追踪明度版\config.json`，不写回公共 `skills.json`。更新代码不会清空该用户目录。通用校准只保存坐标、匹配尺寸和参考亮度，不保存校准截图。

识别和播放音效在本机进行，运行时不上传画面、不调用在线语音服务；安装依赖需要联网。「保存诊断截图」会在本机保存游戏画面，反馈或发布前请自行检查个人信息。素材来源见 [ASSETS.md](ASSETS.md)。

## 测试与制作分发包

源码仓库内安装依赖后运行：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p "test_*.py" -v
.\.venv\Scripts\python.exe scripts/build_release.py
```

分发包输出到 `dist/yysls-overlay.zip`，包含运行代码、`skills.json`、表中引用的 PNG、原有必要边框和四个提醒音。打包脚本按清单收集，不递归打包本地素材库、截图、个人配置或 Git 历史。分享自定义版本时仍应检查自己添加的资源内容。

自动测试覆盖配置校验、多项独立识别、亮暗转换、遮挡保护、计时与资源打包。测试素材为技能原图、单个裁剪图标与合成画面；通过测试不代表实战准确率。Windows 游戏内多屏、实际冷却遮罩、Buff 换槽及录屏效果仍需实机验证。
