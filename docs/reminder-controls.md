# 提醒浮层、图标与音效

v2.6.1 使用两个共享选区：威威易伤、真气失衡、失魂搜索 Debuff 栏区；骑龙、笛子、千灯搜索奇术区。`skills.json` 的 `category` 决定搜索区域，无需逐技能选区或校准。完整步骤和升级说明见 [README](../README.md)。下文专用声音和刷新选项主要针对失魂与笛子。

在 Python 提醒器的「常用设置」中打开「浮层位置 / 音效设置」。

## 文字模式

失魂和笛子分别设置「技能名」与「浮层文字」，支持：

- `{%d}`：剩余秒数，向下取整、最低为 0。
- `{%s}`：对应提醒的技能名。

例如技能名填「打响指」，文字填「{%s}！还剩 {%d} 秒」。笛子可用事件的剩余秒数为 0，默认文字是「{%s}好了」。点「保存并关闭」保存设置。

## 图标模式

将浮层模式切换为「图标」，可选择底色，并开关倒数数字。左边是失魂图案，右边是笛子图案。识别不到游戏中的对应图标时隐藏，仍可拖动并记住位置。

图标随着时间流逝，从中心的 12 点方向开始顺时针逐渐变灰；结束时全灰。失魂使用已经建立的 21 秒时间轴。目标仍可见但未建立时间轴，或计时到期而刷新未确认时，倒数显示「?」，不持续显示 0，也不自动重开一轮。

笛子图标只显示**使用后的技能冷却**，不显示“距离下次提醒”：

- 先连续确认笛子可用，然后在图案仍然存在的情况下连续确认它变暗，才在检测到第一次变暗的时刻开始计时。
- 奇术栏消失时隐藏笛子浮层，清除待确认的使用事件，不启动冷却。重新出现时若已变暗，不推测消失期间的使用时间；此前已确认的冷却不会因隐藏而重新起算。
- 完整冷却默认为用户确认的 **24 秒**。旧配置的未知时长（0）首次加载自动迁移为 24 秒；已自定义的非零时长保留。后续仍可手动调整。
- 可用状态和重复语音提醒都不会启动、重置冷却；重新变为可用时清除冷却计时。
- 启动监测时如果笛子已经在冷却，不知道此前使用时刻，因此不显示推测数字。
- 旧配置中的“下次提醒”模式自动迁移为使用后冷却，不再用重复提醒间隔代替技能冷却。

当前按检测到的使用时刻和配置时长推算，不直接读取奇术栏冷却数字。游戏中有减冷却或重置时，需要匹配实际配置；检测到再次可用会立即校正。

失魂原图模式以近期亮度为基线，连续确认亮度跃升或倒计时扇区回跳后重新建立 21 秒轴并重新允许到期提醒。它不再依赖旧模板的“先暗到 50%”门槛。归零本身不会自动再开一轮；归零后目标消失再重新挂上，可以重新建立时间轴。

## 检测频率与诊断

「高级参数 → 频率 / 原图匹配」可调整全局搜索频率、追踪频率、原图最低匹配分数（默认 0.90）、多目标分差（0.04）、刷新扇区最小回跳（0.25）及允许观测间隔（2 秒）。共享区搜索按各项目独立计时；实际频率受截图与识别耗时限制，提高设定值不保证达到对应帧率。降低分数或分差可能增加误识别；旧版 Sobel 参数不影响原图匹配。

短暂漏检立即隐藏图标，但保留刷新前基线；超过允许观测间隔清空旧时间轴。重捕获保护期间不再用新亮度覆盖旧基线，避免刷新已经发生却漏判。扇区回跳可辅助识别亮度变化较小的刷新，仍需连续帧确认。

「共享区 / 笛子」可调整共享搜索频率（默认 10 Hz）、原图最低匹配分数（默认 0.80）、可用参考亮度及笛子亮暗状态的确认帧数。降低匹配分数可能增加误识别。图案存在判断依赖共享奇术区内的原图形状匹配，仍需实机确认背景变化、冷却遮罩下的效果。

「保存调试」导出的状态 JSON 包含最近最多 1500 次失魂观测（loss_trace）：匹配分数、拒识原因、扇区、亮度与刷新判断、耗时和时间轴起点。若仍漏掉首次续时，可用这段记录定位具体原因。

「预览并拖动」可以在不运行监测时调整位置；图标预览循环演示失魂倒计时、笛子按已填写的冷却时长演示；未填写则保持可用。启动监测后预览切换为真实状态，不会继续播放演示倒数。文字提醒平时显示 900 毫秒，拖动期间暂停自动隐藏，预览保持显示直到关闭设置。

## 内置声音

每个提醒都能选择电子合成音、百度语音或自定义 PCM WAV。默认百度语音分别说「笛子好了」「打响指了」。WAV 已随仓库打包，播放无需联网。自定义文件复制到用户配置目录，原文件移动后仍可播放。修改浮层文本不会更改固定的内置录音。

主界面「声音提醒」是总开关；设置窗口里失魂、笛子各有「启用此提醒的语音 / 音效」勾选框。取消任一声音勾选立即保存并停止当前语音，相应后续事件保持静音；总开关关闭时两种提醒都静音。手动点击「试听」仍可试听。「画面提醒」关闭时仍可手动预览。播放依赖 Windows `winsound`；文件损坏或丢失时回退蜂鸣。

## 选区与本机保存

Debuff 栏共享区域、奇术共享区域、勾选状态、浮层位置、文字、模式和音效选项均保存在：

```text
%APPDATA%\尘Buff提醒器_追踪明度版\config.json
```

选择区域后立即保存，重新打开软件直接使用，不必再选。下载新版或换项目目录不会清空该配置。当整条栏区移出原选区时需要重新框选；图标在栏区内部换槽无需重选。界面摘要显示已保存的两个区域。

旧版单独笛子选区和 `skill_calibrations` 不再用于实时监控；升级后重新框选整条奇术区。新版保存使用临时文件替换，避免写入中断留下半个 JSON。选区坐标按截图比例映射回物理桌面坐标，支持负坐标副屏。

## 浮层不会参与识别

默认不允许截图或录屏捕获浮层。需要录制时，在「浮层位置 / 音效设置」勾选「允许截图/录屏捕获浮层」，点击「保存并关闭」或「预览并拖动」生效；设置会保存，文字、图标和预览均适用。录屏请选择显示器/桌面捕获，单独捕获游戏窗口通常不包含独立浮层。开启后请将浮层移出敌方 Buff 栏和笛子检测区域，发生遮挡时程序会跳过识别。

开关关闭时，Windows 浮层创建时先保持隐藏，对实际顶层窗口设置 `WDA_EXCLUDEFROMCAPTURE`，然后显示；重新映射时重设。文字、图标和预览统一处理，避免截到自己的图标形成循环。

系统不支持或拒绝截图排除时，截图前后会检查浮层遮挡与移动状态：重叠或浮层正在移动的检测帧直接跳过，不会把遮挡误当作技能消失或冷却开始。此时界面提示移开浮层。正常支持排除的 Windows 上，浮层可以与选区重叠而不阻断检测。图标圆角外和两图标间距使用透明像素，Windows 窗口同时设置透明色键。
